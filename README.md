### Портфоліо Досліджень (Sanitised Case Studies)

> *Усі дослідження виконувалися за міжнародним Протоколом Берклі. Повні знеособлені PDF-досьє (30+ сторінок) не публікуються у відкритому доступі з міркувань OPSEC та надаються рекрутерам / HR за особистим запитом.*

  **Case 01: Strategic Defense Conglomerate Analysis**
  * **Тип об'єкта:** Холдингова структура ВПК РФ (морське приладобудування, 14 НИИ/заводів).
  * **Завдання:** Картографування системи управління, виявлення реальних власників та оцінка залежності від ГОЗ.
  * **Застосована методологія:** Протокол Берклі (`[Ф]`, `[Г]`, `[П]`), аналіз ЄДРЮЛ, аналіз фінансової звітності (МСФО), деанонімізація 22 осіб керівного складу за печатками/підписами.
  * **Доступ:** `[Full Sanitised PDF Available Upon Request]`

  **Case 02: Supply Chain & UAV Component Proxy**
  * **Тип об'єкта:** Сервісне підприємство-прокладка (схема обходу санкцій для БПЛА).
  * **Завдання:** Розслідування аномального зростання виручки (у 17 разів) та пошук прихованих виробничих потужностей.
  * **Застосована методологія:** Аналіз вакансій (hh.ru) для локалізації цеху, парсинг зачищеного сайту через власну утиліту `wayback_scraper`, відновлення зв'язку з розробниками мультикоптерів (Іжевськ).
