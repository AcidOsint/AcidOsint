### Власні Інструменти 

  **`tg_toolkit`** — *OSINT-профайлінг та парсинг експортів Telegram.*
  * **Опис:** Утиліта на чистому Python без сторонніх залежностей для зшивки, очищення від системного шуму, структурного парсингу та автоматичного вилучення сутностей (теги, посилання, пошти, криптокоманди/гаманці, телефони) з сирих HTML/TXT дампів Telegram Desktop. Включає модуль локального Grep-пошуку.

  **`wayback_scraper`** — *Автоматизована викачка та відновлення зачищених сайтів.* 
  * **Опис:** Інструмент для автоматизованої викачки, фільтрації та відновлення зачищених снапшотів сайтів з API Wayback Machine.

  **`maltego-transforms`** — *Кастомні трансформи для візуалізації зв'язків.* `[In Development / Coming Soon]`
  * **Опис:** Набір власних трансформацій під Maltego для автоматизованої побудови графу для работи по СНД простору
